# 팩트체크 도구

주장 한 문장을 넣으면 웹에서 근거를 찾고(Tavily), 그 근거만 보고 6단계로 판정한다(Claude).
판정 단계: 사실 / 대체로 사실 / 절반의 사실 / 대체로 사실 아님 / 사실 아님 / 판단 유보.

## 쓰는 사람

관리자에게 받은 주소로 접속한다. 처음 검증할 때 비밀번호를 한 번 물어보고, 그 뒤로는 그 브라우저가 기억한다.

- 한동안 아무도 쓰지 않았으면 첫 접속에 1분 가까이 걸린다(무료 서버가 잠들었다 깨는 시간). 그다음부터는 바로 열린다.
- 하루에 쓸 수 있는 판정 횟수에 상한이 있다. 다 쓰면 다음 날 한국 시간 오전 9시에 풀린다.
- 검증이 끝나면 오른쪽 「검증 기록」에 자동으로 쌓인다. 기록을 누르면 API를 다시 부르지 않고 그때 결과를 다시 보여 준다. 기록은 각자 브라우저에만 저장되므로, 오래 보관할 것은 「CSV로 내보내기」로 받아 둔다.
- 판정은 찾은 근거 몇 건에 기댄 참고 의견이다. 기사에 쓰기 전에 근거 링크를 직접 열어 확인한다.

## 관리자: 공유 서버 배포 (Render)

검색·판정 요금은 서버에 넣은 키 하나로 나간다. 판정 한 번에 Sonnet 5.5 기준 대략 $0.01~0.03이 든다.

1. https://render.com 에 GitHub 계정으로 가입한다.
2. `New` → `Blueprint` → 이 저장소(`factcheck`)를 고른다. `render.yaml`을 읽어 설정이 자동으로 채워진다.
3. 값을 넣으라는 칸 세 개를 채운다.
   - `TAVILY_API_KEY`, `CLAUDE_API_KEY`: API 키
   - `FACTCHECK_PASSWORD`: 동료들에게 알려 줄 공용 비밀번호
4. `Apply`를 누르면 몇 분 뒤 `https://factcheck-xxxx.onrender.com` 같은 주소가 생긴다. 이 주소와 비밀번호를 동료들에게 알려 준다.

- `main`에 push하면 자동으로 다시 배포된다.
- 하루 판정 상한은 `FACTCHECK_DAILY_LIMIT`(기본 200회)로 바꾼다. 서버가 재시작되면 0부터 다시 세므로 대략적인 안전장치다.
- **진짜 상한은 Anthropic 콘솔에서 건다.** https://console.anthropic.com 의 Limits(사용 한도)에서 월 지출 한도를 정해 두면 그 이상은 청구되지 않는다.
- 비밀번호가 새 나갔으면 Render의 `Environment`에서 `FACTCHECK_PASSWORD`를 바꾸면 된다.
- 키는 저장소에 절대 커밋하지 않는다. 이 저장소는 공개 저장소다.

## 관리자: 내 PC에서 실행

1. Python 3.10 이상을 설치한다(설치 화면에서 「Add python.exe to PATH」 체크).
2. `팩트체크 열기.bat`을 더블클릭한다. 처음 한 번은 패키지를 설치하고, `.env`가 없으면 메모장을 열어 키를 넣게 한다.
3. 브라우저에 `http://127.0.0.1:8765`가 뜬다. 검은 창을 닫으면 꺼진다.

`.env`에 키를 넣는 형식은 `.env.example`을 본다. `.env`는 깃허브에 올라가지 않는다.
